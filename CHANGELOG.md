# Changelog

## 0.1.0 — 2026-10-20

- Initial public macOS and Windows development release.
- Twelve stable script slots, multiple profiles, circular arc labels, and a native radial launcher.
- Configuration editor with script library, drag-to-swap, import/export, and scene-neutral validation fixtures.
- Hover/press feedback, Filee-inspired per-slice close animation, and a reduced-motion fallback.
- macOS universal AppKit helper and Windows PowerShell/WinForms helper.
- English and Chinese documentation, offline installation guides, CI, and checksum-verified release archives.
